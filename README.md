# TKH Phase 2 — Cloud Engineering & DevSecOps Portfolio

This repository contains my Phase 2 cloud engineering and DevSecOps labs for The Knowledge House Fellowship. Each project builds real-world skills in Terraform automation, CI/CD pipelines, cloud security, identity federation, and incident response. The work in this phase demonstrates my ability to design secure infrastructure, enforce least privilege, automate deployments, and implement shift-left security controls.
